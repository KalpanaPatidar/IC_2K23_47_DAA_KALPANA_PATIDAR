# Performance Analysis Report

The analyzer measures Bubble Sort, Insertion Sort, Merge Sort, Quick Sort, and Heap Sort for five input sizes and three input cases. Results are stored in `performance_results.csv`; the graph is generated by `plot_performance.py`.

The quadratic algorithms are expected to grow much faster as `n` increases, especially for reverse-sorted data. Merge Sort and Heap Sort should remain close to O(n log n) across all cases. Quick Sort is expected to perform well on random data and degrade on the sorted and reverse-sorted cases because the implementation uses a fixed final-element pivot.

Record machine details, compiler flags, and the generated graph alongside the CSV when submitting experimental results.
