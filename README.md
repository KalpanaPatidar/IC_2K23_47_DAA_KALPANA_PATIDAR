📌 About the Repository

This repository contains practical implementations and experiments related to Design and Analysis of Algorithms (DAA).

The objective is to understand different algorithms, implement them using programming, analyze their efficiency, and compare their performance based on time and space complexity.

🎯 Problem Statement

To implement and analyze various searching and sorting algorithms and study their performance using theoretical complexity analysis and practical execution.

The main objectives are:

- Implement searching algorithms to find elements efficiently.
- Implement sorting algorithms to arrange data in a specific order.
- Analyze the time and space complexity of algorithms.
- Compare algorithm performance for different input sizes.
- Understand the importance of algorithm selection and optimization.

💡 Approach

The practical work is divided into four major modules:

1. Searching Algorithms

This module focuses on searching elements from a given collection of data.

- Implement searching techniques.
- Accept input data and the target element.
- Display whether the element is present.
- Analyze the number of operations required.

Complexity examples:

Algorithm| Best Case| Average Case| Worst Case
Linear Search| O(1)| O(n)| O(n)
Binary Search| O(1)| O(log n)| O(log n)

Note: Binary Search requires sorted input.

2. Sorting Algorithms

This module focuses on arranging elements in ascending or descending order.

- Implement different sorting techniques.
- Process input arrays.
- Display sorted results.
- Analyze the efficiency of sorting algorithms.

Complexity examples:

Algorithm| Best Case| Average Case| Worst Case
Bubble Sort| O(n)| O(n²)| O(n²)
Selection Sort| O(n²)| O(n²)| O(n²)
Insertion Sort| O(n)| O(n²)| O(n²)
Merge Sort| O(n log n)| O(n log n)| O(n log n)
Quick Sort| O(n log n)| O(n log n)| O(n²)

3. Sorting Performance Comparison System

This module focuses on comparing the performance of sorting algorithms.

- Execute sorting algorithms on input datasets.
- Measure execution time.
- Compare results for different input sizes.
- Identify which algorithms perform better under different conditions.

4. Algorithm Performance Analyzer

This module focuses on analyzing algorithm efficiency.

- Study algorithm execution performance.
- Understand the relationship between input size and execution time.
- Analyze time and space complexity.
- Compare theoretical and practical performance.

⏱️ Time and Space Complexity Analysis

Time complexity describes how the execution time of an algorithm grows with input size.

Space complexity describes how much additional memory an algorithm requires.

Complexity| Meaning
O(1)| Constant
O(log n)| Logarithmic
O(n)| Linear
O(n log n)| Linearithmic
O(n²)| Quadratic
O(2ⁿ)| Exponential

The analysis helps determine which algorithm is suitable for a particular problem and input size.
